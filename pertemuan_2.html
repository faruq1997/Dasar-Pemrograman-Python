1. Sintaks Dasar, Statement & Komentar

Semua instruksi yang dapat dieksekusi oleh Python disebut sebagai Statement. Dokumentasi atau catatan yang tidak dieksekusi disebut Komentar.

1. Statement Python

Setiap perintah tunggal yang diproses interpreter. Di Python, kita tidak perlu mengakhiri statement dengan titik koma (;). Satu baris perintah langsung dieksekusi secara berurutan. 

# Contoh Statement:
print("ini merupakan statement dalam bahasa python")
Output: ini merupakan statement dalam bahasa python

2. Komentar dalam Python

Tanda pagar (#) digunakan sebagai komentar atau catatan pengingat. Apapun teks yang ditulis setelah tanda # dijamin pasti tidak akan terbaca oleh program. 

#apapun yang ditulis disini
#pasti tidak akan terbaca oleh program
nama = "Faruq"  # ini komentar di samping baris
Sangat bermanfaat untuk dokumentasi & debugging kode!

3. Tanda Kutip di Python

Python menggunakan tanda kutip tunggal ('), ganda ("), maupun triple (''' atau """). Syarat utamanya adalah diawali dan diakhiri oleh tanda kutip yang sama. Tanda kutip tiga dipakai untuk string multibaris. 

huruf = 'U'
kata = "kata"
kalimat = "Ini adalah kalimat"
paragraf = """ Ini adalah paragraf
terdiri dari beberapa baris """

print(huruf) # Menghasilkan: U

2. Variabel dan Tipe Data

Pahami perbedaan fundamental: Variabel adalah wadah nilai yang dapat berubah-ubah, sedangkan Tipe Data adalah sifat nilainya yang tetap (konstanta).

Variabel

Variabel merupakan nilai yang bisa berubah-ubah. Variabel bertindak sebagai label penunjuk alamat di dalam memori komputer. 

# Format: Nama Variabel = Nilai Variabel
nama_variabel = 1000
nama_variabel = 2500  # Nilai berhasil diubah

Tipe Data

Tipe Data merupakan nilai yang sifatnya tetap / konstanta. Angka 1000 selalu bertipe integer dan "Python" selalu bertipe string. 

# Sifat data tetap sebagai konstanta:
print(type(1000))      # <class 'int'>
print(type("Python"))  # <class 'str'>

Deklarasi Variabel di Python

Python menerapkan Dynamic Typing. Cukup ketikkan nama variabel, tanda sama dengan (=), dan nilainya. Tidak perlu mengetik tipe data secara eksplisit. 

nama_variabel = 1000
nama = "Faruq"
ipk = 3.85
lulus = True

Aturan Penamaan Variabel

Kaidah wajib nama variabel Python:

  • Hanya boleh huruf (a-z, A-Z), angka (0-9), dan garis bawah (_).
  • TIDAK boleh diawali angka (contoh: 1angka ❌).
  • TIDAK boleh mengandung spasi atau simbol khusus (@, -, $, %).
  • Bersifat Case-Sensitive (nama ≠ Nama).
  • Dilarang memakai Reserved Keywords (if, for, class, def, return).

4. List Python: Fungsi, Method & Visualizer

List adalah tipe data terpopuler di Python untuk menampung banyak data heterogen sekaligus. Pelajari fungsi built-in dan method pengolahannya.

Daftar Function List pada Python (Cell 31 Colab)

Python Function Penjelasan
len(list) Memberikan total panjang / jumlah elemen dalam list.
max(list) Mengembalikan item dari list dengan nilai paling maksimal.
min(list) Mengembalikan item dari list dengan nilai paling minimal.
list(seq) Mengubah tuple atau sequence lain menjadi bentuk list.

Daftar List Method pada Python (Cell 34 Colab)

Method Penjelasan
list.append(obj) Menambahkan objek obj ke posisi paling akhir list.
list.count(obj) Jumlah kemunculan berapa kali obj terdapat dalam list.
list.extend(seq) Tambahkan seluruh isi seq ke dalam list.
list.index(obj) Mengembalikan indeks terendah tempat munculnya obj.
list.insert(idx, obj) Sisipkan objek obj ke dalam list pada posisi index tertentu.
list.pop([obj]) Menghapus dan mengembalikan elemen terakhir (atau index tertentu).
list.remove(obj) Menghapus kemunculan pertama obj dari dalam list.
list.reverse() Membalik urutan seluruh elemen list di tempat.
list.sort() Mengurutkan elemen list (ascending atau custom).

5. Aturan Indentasi & Line Continuation (\)

Python tidak menggunakan tanda kurung kurawal { } untuk membungkus blok kode. Sebagai gantinya, Python mengandalkan Indentasi (spasi menjorok ke dalam).

Aturan Indentasi Python

Awas: Unexpected Indent!

Perhatikan penulisan kode di dalam percabangan (seperti if atau else). Kode harus menjorok ke kanan secara seragam (standar 2 atau 4 spasi). Jika tidak konsisten, akan muncul pesan error: IndentationError: unexpected indent. 

ipk = 2.75

if ipk < 2.75:
  print("Tidak lulus")
  print("Perlu dievaluasi")
else:
  print("Lulus")
  print("Langsung Wisuda")
Eksekusi Sukses:
Lulus
Langsung Wisuda

Line Continuation (Backslash \)

Catatan Penting Cell 46-47 Colab

Umumnya kita menulis satu statement dalam satu baris. Namun bila baris kode terlalu panjang dan ingin disambung ke baris berikutnya (enter), cukup tambahkan karakter backslash (\) di akhir baris. 

# Menggunakan tanda \ untuk sambung baris baru:
newline = 1 + 2 +\
3 + 4 \
+ 5

print(newline)
Hasil Evaluasi Perhitungan:
1 + 2 + 3 + 4 + 5 = 15

Python otomatis membaca ketiga baris di atas sebagai satu kesatuan operasi matematika tunggal tanpa SyntaxError.

8. Operator Aritmatika Dasar

Python menyediakan operator aritmatika lengkap untuk melakukan kalkulasi matematis terhadap tipe data numerik.

Operator Nama Operasi Contoh Kode Hasil Penjelasan
+ Penjumlahan 10 + 5 15 Menjumlahkan dua buah bilangan atau menggabungkan string.
- Pengurangan 10 - 4 6 Mengurangkan bilangan kanan dari bilangan kiri.
* Perkalian 7 * 6 42 Mengalikan dua bilangan atau menduplikasi string.
