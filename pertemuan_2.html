Fondasi Koding

1. Sintaks Dasar, Statement & Komentar

Segala baris kode yang dapat dieksekusi oleh Python disebut sebagai Statement. Untuk memberi dokumentasi atau catatan pengingat tanpa dieksekusi, kita menggunakan Komentar.

Statement Python

Setiap perintah tunggal yang diproses oleh interpreter. Di Python, kita tidak perlu mengakhiri statement dengan titik koma (;). 

# Contoh Statement:
print("Ini merupakan statement dalam bahasa Python")
total_nilai = 95

Komentar (#)

Tanda pagar (#) digunakan untuk menulis catatan atau menonaktifkan kode sementara. Teks setelah tanda # diabaikan total oleh komputer. 

# Ini adalah komentar 1 baris
# Apapun yang ditulis disini tidak terbaca program
x = 10  # Komentar inline di samping kode

Tanda Kutip di Python

Python mendukung tanda kutip tunggal ('), ganda ("), dan tiga ("""). Tanda kutip tiga berguna untuk teks multibaris atau dokumentasi. 

huruf = 'U'
kata = "kata"
paragraf = """Ini adalah paragraf
terdiri dari beberapa baris."""
Penyimpanan Memori

2. Variabel dalam Python

Variabel adalah wadah di dalam memori komputer yang digunakan untuk menampung data atau nilai yang sifatnya dapat berubah-ubah (*mutable*) selama program berjalan.

Deklarasi Variabel

Cukup tuliskan nama variabel diikuti operator penugasan sama dengan (=) dan nilainya. Tidak perlu menentukan tipe data secara manual. 

nama_variabel = 1000
nama_mahasiswa = "Faruq"
status_aktif = True

Aturan Penamaan Variabel

Pedoman penting membuat nama variabel yang benar:

  • Hanya boleh huruf (a-z, A-Z), angka (0-9), dan garis bawah (_).
  • TIDAK boleh diawali oleh angka (misal: 1nilai ❌).
  • TIDAK boleh mengandung spasi atau simbol khusus (@, -, $, %).
  • Bersifat Case-Sensitive (nama berbeda dengan Nama).
  • Tidak boleh menggunakan Reserved Keywords Python (if, for, class, def, import).

3. Macam - Macam Tipe Data

Tipe data menentukan jenis nilai yang disimpan di dalam variabel dan operasi apa saja yang dapat dilakukan terhadapnya. Gunakan fungsi type() untuk memeriksa tipe data suatu nilai.

Transformasi Nilai

4. Konversi Tipe Data (Type Casting)

Type casting adalah proses mengubah nilai dari satu tipe data ke tipe data lainnya menggunakan fungsi konversi bawaan seperti int(), float(), str(), hex(), atau bool().

Type Casting Interactive Lab

Masukkan nilai awal, pilih target tipe data tujuan, lalu lihat bagaimana Python melakukan konversi secara instan!

Hasil Konversi:
23092022
Tipe Data: <class 'int'>

Nilai berhasil diubah menjadi bilangan bulat integer.

Kalkulasi Cepat

5. Operator Aritmatika Dasar

Python menyediakan operator aritmatika lengkap untuk melakukan kalkulasi matematis terhadap tipe data numerik.

Operator Nama Operasi Contoh Kode Hasil Penjelasan
+ Penjumlahan 10 + 5 15 Menjumlahkan dua buah bilangan atau menggabungkan string.
- Pengurangan 10 - 4 6 Mengurangkan bilangan kanan dari bilangan kiri.
* Perkalian 7 * 6 42 Mengalikan dua bilangan atau menduplikasi string.
/ Pembagian (Float) 10 / 4 2.5 Menghasilkan pembagian riil desimal (selalu bertipe float).
// Floor Division 10 // 4 2 Pembagian bulat ke bawah dengan membuang angka desimalnya.
% Modulus 10 % 3 1 Sisa hasil bagi (10 dibagi 3 bernilai 3 sisa 1).
** Perpangkatan 2 ** 3 8 Menghitung 2 pangkat 3 (2 × 2 × 2 = 8).
