Dasar Fondasi

Apa itu Pemrograman & Kenapa Python?

Komputer adalah mesin yang sangat cerdas dan cepat, tetapi membutuhkan instruksi presisi. Bahasa pemrograman adalah jembatan komunikasi antara logika manusia dan instruksi komputer.

Apa itu Pemrograman?

Pemrograman adalah proses menyusun urutan perintah terstruktur (algoritma) yang memberitahu komputer cara menyelesaikan suatu permasalahan secara otomatis, efisien, dan akurat.

Keterbacaan Tinggi

Python menganut filosofi "Readability Counts". Tidak ada kurung kurawal rumit atau titik-koma yang membingungkan. Kode terlihat rapi dan elegan berkat sistem indentasi.

Multi-Paradigma

Mendukung berbagai gaya penulisan kode: prosedural, berorientasi objek (OOP), hingga fungsional. Sangat fleksibel untuk proyek kecil maupun sistem berskala besar.

Ekosistem Raksasa

Memiliki puluhan ribu pustaka (*libraries*) gratis seperti Pandas, NumPy, Scikit-Learn, TensorFlow, Django, dan FastAPI untuk berbagai kebutuhan industri modern.

Interpreted Language

Kode dieksekusi baris demi baris oleh Python Interpreter tanpa perlu tahap kompilasi terpisah terlebih dahulu, membuat proses debugging jauh lebih instan.

Komunitas Global

Merupakan bahasa terpopuler di dunia versi indeks TIOBE & Stack Overflow dengan jutaan pengembang yang siap membantu saat Anda menemukan kendala.

Perbandingan Syntax "Hello World"

Lihat betapa ringkas dan intuitifnya Python dibandingkan bahasa pemrograman lain:

# Menampilkan teks di Python — Hanya 1 Baris Sederhana!
print("Halo Dunia! Selamat Belajar Python.")

Sejarah & Perjalanan Python

Bagaimana sebuah proyek liburan Natal berkembang menjadi bahasa pemrograman nomor 1 di dunia teknologi dan kecerdasan buatan.

Desember 1989

Kelahiran Ide Python

Diciptakan oleh Guido van Rossum di lembaga riset Centrum Wiskunde & Informatica (CWI) di Belanda. Ia mengisi waktu libur Natal dengan membuat penerus bahasa ABC.

Februari 1991

Rilis Publik Pertama (v0.9.0)

Kode sumber Python dirilis ke publik dengan fitur kelas (OOP), fungsi, penanganan eksepsi, dan tipe data inti seperti list dan dict.

Fakta Unik Nama

Bukan dari Ular!

Nama "Python" diambil dari serial komedi sketsa BBC favorit Guido: "Monty Python’s Flying Circus", mencerminkan sifat bahasa yang menyenangkan dan tidak membosankan.

Oktober 2000

Python 2.0

Menghadirkan fitur modern seperti List Comprehensions dan manajemen memori dengan Garbage Collection otomatis berbasis *cycle-detecting*.

Desember 2008

Python 3.0 (Python 3000)

Perombakan arsitektur besar untuk memperbaiki inkonsistensi desain lama. String menggunakan Unicode secara default dan print resmi menjadi sebuah fungsi.

Era Modern (3.10 - 3.13+)

Raja Kecerdasan Buatan (AI)

Python menjadi fondasi utama revolusi Artificial Intelligence (AI), Data Science, otomatisasi cloud, dan riset teknologi terdepan di seluruh dunia.

Tools Kita: Google Colaboratory

Google Colab adalah platform komputasi awan (*cloud*) berbasis Jupyter Notebook yang disediakan gratis oleh Google untuk menulis dan mengeksekusi kode Python langsung dari browser Anda.

Cloud Based

Semua kode diproses di server Google. Laptop spek standar pun dapat menjalankan program berat tanpa hambatan.

Kolaborasi Mudah

Berbagi file notebook semudah membagikan Google Docs dengan tautan link atau menyimpan langsung ke repositori GitHub.

Akses GPU & TPU Gratis

Dukungan akselerator grafis gratis untuk komputasi data besar, machine learning, dan deep learning.

Text (Markdown) + Code

Kombinasi penjelasan materi berformat rapi dengan blok kode interaktif yang bisa langsung dijalankan.

Shortcut Keyboard Penting Google Colab

Gunakan pintasan keyboard ini untuk meningkatkan kecepatan belajar dan produktivitas coding Anda:

Kombinasi Tombol Aksi / Fungsi Kegunaan
Ctrl + Enter Run Cell Menjalankan cell aktif dan kursor tetap berada di cell tersebut.
Shift + Enter Run & Pindah ke Bawah Menjalankan cell aktif lalu otomatis berpindah/membuat cell baru di bawahnya.
Alt + Enter Run & Sisipkan Cell Menjalankan cell aktif dan langsung menyisipkan cell kosong di bawahnya.
Ctrl + M lalu A Add Cell Above Menambahkan cell kode baru tepat di atas cell saat ini.
Ctrl + M lalu B Add Cell Below Menambahkan cell kode baru tepat di bawah cell saat ini.
Ctrl + M lalu D Delete Cell Menghapus cell yang sedang aktif.
Ctrl + M lalu M Convert to Markdown Mengubah tipe cell kode menjadi teks penjelasan (Markdown).
