Py-Man Quest!

Makan pelet Python untuk mempelajari variabel, matematika pangkat/akar, dan logika game!

Inspektor Variabel Python (Live)

Real-time Game State
// Data Jenis Variabel Karakter:
hp = 3 # Integer
player_name = "Py-Man" # String
inventory = ["Super-Power"] # List/Array
is_super_mode = False # Boolean
// Live Math & Logika Game:
score = 0
power_damage = score ** 2 -> 0 # Pangkat (**2)
sqrt_speed = score ** 0.5 -> 0.0 # Akar (**0.5)
can_eat_bugs = is_super_mode and (hp > 0) -> False

Empat Tipe Data Dasar Python:

  • Integer: Angka bulat tanpa desimal. Contoh: hp = 3
  • String: Teks dalam petik. Contoh: name = "Py-Man"
  • Array / List: Wadah banyak data dalam kurung [...]
  • Boolean: Kondisi pasti True atau False.

Operasi Pangkat & Akar Kuadrat:

⚡ Pangkat (**): 3 ** 2 artinya 3 × 3 = 9.

🌱 Akar Kuadrat (** 0.5): Memangkatkan dengan 0.5 sama dengan akar kuadrat! Contoh: 16 ** 0.5 = 4.0 (Atau pakai math.sqrt(16)).

Operator Logika Python:

and: True jika SEMUA kondisi bernilai True.
or: True jika SALAH SATU kondisi bernilai True.
not: Membalikkan boolean (not False -> True).

Cara Bermain Py-Man Quest

1. Kontrol: Gunakan tombol panah keyboard atau D-Pad di layar untuk menggerakkan Py-Man (kuning).

2. Pelet Koding: Makan Pelet Kuning untuk menambah skor. Perhatikan variabel di panel kanan yang otomatis terupdate!

3. Question Stars (⭐): Makan bintang untuk memicu tantangan koding. Jawaban benar memberikan status is_super_mode = True!

4. Bug Ghosts (👻): Hindari Hantu Bug jika belum Super Mode. Saat Super Mode aktif, makan para bug untuk bonus XP besar!
