Bagian 01

Apa Itu Percabangan & Indentasi Python?

Pengambilan keputusan (*decision making*) adalah kunci bagaimana komputer merespons berbagai skenario yang berbeda.

Definisi Percabangan (*Conditional Statement*)

Percabangan atau Pengkondisian adalah cara yang digunakan untuk mengambil keputusan berdasarkan kondisi tertentu. Percabangan mengevaluasi kondisi atau ekspresi logika yang menghasilkan nilai boolean (True atau False).

Jika Kondisi Benar (True):

Pernyataan di dalam blok kondisi tersebut akan dieksekusi oleh Python.

Jika Kondisi Salah (False):

Blok kode tersebut dilewati, atau sistem akan mengeksekusi blok cabang alternatif (else).

Aturan Sakral: Indentasi Sebagai Penentu Blok Kode

Tidak seperti bahasa C, C++, Java, atau JavaScript yang menggunakan kurung kurawal { } untuk membungkus blok kode, Python menggunakan indentasi (spasi menjorok ke kanan, standar 4 spasi) setelah tanda titik dua :.

contoh_indentasi.py 
# Tanda titik dua (:) mengawali blok kondisi
if 10 > 5:
    # Indentasi 4 spasi (Menjorok ke kanan)
    print("Statement ini berada di dalam blok IF dan akan dieksekusi!")

# Baris tanpa indentasi berarti berada di LUAR blok IF
print("Statement ini akan SELALU dieksekusi karena berada di luar percabangan.")
Bagian 02

Pernyataan Percabangan Tunggal: if

Digunakan ketika Anda hanya memiliki 1 kondisi aksi yang ingin dijalankan jika syarat terpenuhi.

Sintaks & Cara Kerja

Jika kondisi bernilai True, maka baris instruksi di dalamnya dijalankan. Jika False, program langsung melompat ke baris berikutnya.

sintaks_if.py 
if tes_kondisi:
    # statement dijalankan jika True
    perintah_1()
    perintah_2()

Contoh Kode Nyata

cek_angka.py 
angka = 5

if angka > 0:
    print(angka, "adalah bilangan positif lebih besar dari 0")

# Output:
# 5 adalah bilangan positif lebih besar dari 0

Bagian 03

Pernyataan Percabangan Ganda: if ... else

Menyediakan dua alternatif alur: blok if jika kondisi terpenuhi, dan blok else jika tidak.

Flowchart Logika If-Else

Mulai
Kondisi (nilai >= 75)?
True False
Lulus Ujian!
Tidak Lulus!

Contoh Implementasi Python

kelulusan.py 
nilai = 74

print("Nilai anda adalah:", nilai)

if nilai >= 75:
    print("Selamat, anda lulus!")
else:
    print("Maaf, anda tidak lulus.")

# Contoh cek bilangan genap / ganjil:
bilangan = 17
if bilangan % 2 == 0:
    print(bilangan, "adalah Bilangan Genap")
else:
    print(bilangan, "adalah Bilangan Ganjil")
Bagian 04

Pernyataan Percabangan Majemuk: if ... elif ... else

Digunakan untuk menguji lebih dari 2 kondisi secara berurutan (*cascading conditional statement*).

Kata kunci elif merupakan singkatan dari "else if". Python akan mengevaluasi setiap kondisi dari atas ke bawah. Segera setelah satu kondisi bernilai True, blok tersebut dieksekusi dan Python akan langsung melompati seluruh elif/else berikutnya!

Kalkulator Predikat Nilai Mahasiswa

0 85 100
Aturan Nilai Kuliah:
  • Nilai ≥ 88 → Predikat A (Istimewa)
  • Nilai ≥ 75 → Predikat B (Baik)
  • Nilai ≥ 60 → Predikat C (Cukup)
  • Nilai ≥ 40 → Predikat D (Kurang)
  • Lainnya → Predikat E (Gagal)

Bagian 05

Percabangan Bersarang (*Nested If*)

Meletakkan blok percabangan di dalam blok percabangan lainnya untuk validasi bertingkat.

Nested If sangat sering digunakan ketika keputusan kedua hanya boleh diperiksa jika keputusan pertama sudah benar. Misalnya: Sistem otentikasi login (Periksa Username dulu → jika benar baru periksa Password).

sistem_login_nested.py 
username = input("Username: ")
password = input("Password: ")

# Percabangan Tingkat 1 (Cek Username)
if username == "admin":
    # Percabangan Tingkat 2 (Bersarang di dalam if username)
    if password == "rahasia123":
        print("Login Berhasil! Selamat datang, Admin.")
    else:
        print("Password salah! Akses ditolak.")
else:
    print("Username tidak terdaftar di sistem!")
