Bagian 01

Konsep Dasar String, Immutability & Slicing

String adalah sekuens karakter berurutan di dalam tanda kutip tunggal '...' atau ganda "...".

Karakteristik Utama String

  • Immutable (Tidak Dapat Diubah): Karakter dalam string tidak dapat diganti secara in-place (misal: s[0] = 'H' menghasilkan TypeError).
  • Operasi Penggabungan: Gunakan simbol + untuk menyambung (concatenation) dan * untuk melipatgandakan (repetition).
  • Fungsi len(): Menghitung total jumlah karakter termasuk spasi, angka, dan simbol tanda baca.
string_dasar.py 
var1 = "Hello Python!"
var2 = "I love Python"

print(var1[0])      # Output: H (Indeks ke-0)
print(var2[2:6])    # Output: love (Slicing 2..5)
print(var1[:6] + "World") # Update: Hello World
print("Halo" * 2)   # Output: HaloHalo

Bagian 02

Karakter Escape & Raw String (r"...")

Karakter khusus yang diawali simbol backslash \ untuk memformat baris, tab, dan kutip tanpa menimbulkan SyntaxError.

Daftar Escape Sequences Populer

Karakter Deskripsi Contoh Output
\' Kutip Tunggal (Single Quote) Jum\'at → Jum'at
\" Kutip Ganda (Double Quote) \"Buku\" → "Buku"
\n Baris Baru (Newline / Enter) Teks pindah ke baris bawah
\t Tab Horizontal Memberi spasi tab (4 spasi)
\\ Karakter Backslash Asli Mencetak satu garis miring \

Keajaiban Raw String: r"..."

Pada penulisan alamat direktori file Windows atau Regular Expressions (Regex), backslash sering dianggap escape sequence. Gunakan awalan huruf r (Raw String) agar Python mengabaikan escape character!

raw_string_demo.py 
# Tanpa Raw String (Bisa salah karena \n dan \t)
path_salah = "C:\new_folder\test.txt"
print(path_salah)

# Menggunakan Raw String r"..." (Aman & Utuh)
path_benar = r"C:\new_folder\test.txt"
print(path_benar)  # Output: C:\new_folder\test.txt
Bagian 03

String Formatting: F-String, .format() & %

Evolusi pemformatan teks di Python: dari operator lama %, method .format(), hingga standar modern f-string.

1. Format Spefifers %

Gaya bahasa C klasik:

"Nama %s, Umur %d" % ("Faruq", 25)

2. Method .format()

Diperkenalkan di Python 2.7+:

"Total: {:.2f}".format(150000.758)

3. F-String (Standard Modern)

Paling cepat, bersih & intuitif (Python 3.6+):

f"Harga: Rp {harga:,.2f}"

                Bagian 05
                
Tipe Bilangan (Numbers) & Modul Matematika

                
Pengolahan angka di Python: Integer, Floating Point, Bilangan Kompleks, serta fungsi modul math dan random.

            


            

                

                    

                         Tipe Data Numerik & Built-in Functions
                    

                    
    
                        
  • int: Bilangan bulat tanpa batas digit (contoh: 42, -100).
    • 
                        
  • float: Bilangan desimal presisi pecahan (contoh: 3.14159).
    • 
                        
  • complex: Bilangan real dan imajiner a + bj (contoh: 2 + 3j).
    • 
                        
  • Fungsi Built-in: abs(-5) → 5, round(3.567, 2) → 3.57, pow(2, 3) → 8, divmod(10, 3) → (3, 1).
    • 
                    


                    

                        

                            

                                
                                
                                
                            

                            math_module.py
                        

                        


import math
import random

print(math.sqrt(64))     # Output: 8.0 (Akar kuadrat)
print(math.ceil(4.2))    # Output: 5 (Pembulatan ke atas)
print(math.floor(4.9))   # Output: 4 (Pembulatan ke bawah)
print(random.randint(1, 100)) # Angka acak 1..100
