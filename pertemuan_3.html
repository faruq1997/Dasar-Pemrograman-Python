Komunikasi Program

1. Input dan Output Dinamis

Program yang baik adalah program yang mampu berinteraksi dengan pengguna. Fungsi input() bertugas mengambil data masukan keyboard, sedangkan print() menampilkan hasil kalkulasi.

Fungsi input()

Fungsi input("Teks Prompt: ") menjeda program sampai pengguna mengetik sesuatu dan menekan tombol Enter. 

# Nilai dari input() SELALU bertipe String (str)!
nama = input("Masukkan nama Anda: ")
umur = int(input("Masukkan usia Anda: ")) # Wajib Type Casting

Format Output Modern (f-string)

Gunakan awalan f"..." dan masukkan variabel ke dalam kurung kurawal {variabel} untuk output yang bersih dan rapi. 

harga = 25000
jumlah = 3
print(f"Total Bayar: Rp{harga * jumlah:,}")
# Output: Total Bayar: Rp75,000

Parameter sep & end

Parameter sep mengatur pemisah antar nilai, dan end mengatur karakter di akhir teks output (default-nya baris baru \n). 

print("Python", "Dasar", "Keren", sep=" - ")
print("Baris satu...", end=" ")
print("Lanjut di baris yang sama!")

2. Operator Penugasan (Assignment)

Operator penugasan digunakan untuk mengisi nilai ke dalam variabel sekaligus melakukan operasi aritmatika secara ringkas dan efisien.

Operator Contoh Kode Ekuivalen Dengan Nilai Awal (a=10) → Hasil Keterangan
= a = 5 a = 5 a = 5 Memberi nilai langsung ke variabel.
+= a += 5 a = a + 5 a = 15 Tambah nilai variabel saat ini.
-= a -= 3 a = a - 3 a = 7 Kurang nilai variabel saat ini.
*= a *= 4 a = a * 4 a = 40 Kalikan nilai variabel saat ini.
/= a /= 2 a = a / 2 a = 5.0 (float) Bagi desimal nilai variabel saat ini.
%= a %= 3 a = a % 3 a = 1 Sisa bagi (modulus) nilai variabel.
**= a **= 2 a = a ** 2 a = 100 Pangkatkan nilai variabel saat ini.
Evaluasi Kondisi

3. Operator Perbandingan (Relasional)

Operator perbandingan membandingkan dua nilai dan selalu menghasilkan nilai boolean (True atau False).

Sama Dengan (==) vs Tidak Sama (!=)

== memeriksa kesamaan nilai (beda dengan = penugasan), sedangkan != memeriksa ketidaksamaan. 

print(10 == 10)  # True
print(10 == "10") # False (beda tipe data!)
print(10 != 5)   # True

Lebih Besar / Kecil (>, <, >=, <=)

Memeriksa besaran nilai numerik untuk menentukan ambang batas (misal: nilai ujian kelulusan). 

nilai_mhs = 78
kriteria_lulus = 75

is_lulus = nilai_mhs >= kriteria_lulus
print("Status Lulus:", is_lulus) # True

Identitas (is) & Keanggotaan (in)

is memeriksa alamat memori yang sama. in memeriksa apakah suatu elemen terdapat dalam sequence (string/list). 

teks = "Belajar Dasar Pemrograman"
print("Dasar" in teks)      # True
print("Java" not in teks)   # True

Operator logika menggabungkan beberapa kondisi perbandingan menjadi satu keputusan logika akhir.

Level Biner CPU

5. Operator Bitwise (Biner 0 & 1)

Operator bitwise melakukan operasi logika langsung pada setiap bit representasi bilangan biner angka tersebut (mengingatkan kita pada konsep Biner Pertemuan 1).

Operator Nama Operasi Contoh Kode Biner Operasi Hasil
& Bitwise AND 1 & 64 00000001 & 01000000 0 (00000000)
| Bitwise OR 1 | 64 00000001 | 01000000 65 (01000001)
^ Bitwise XOR 1 ^ 64 00000001 ^ 01000000 65 (01000001)
~ Bitwise NOT (Invert) ~1 -(x + 1) -2
<< Shift Left (Geser Kiri) 64 << 1 01000000 << 1 = 10000000 128 (dikali 2^n)
>> Shift Right (Geser Kanan) 64 >> 1 01000000 >> 1 = 00100000 32 (dibagi 2^n)
