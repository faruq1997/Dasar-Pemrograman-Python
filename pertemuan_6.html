Bagian 01

Apa Itu List & Bagaimana Indexing Bekerja?

List adalah struktur data sekuensial (berurutan) di Python yang dapat menampung satu atau lebih elemen dengan tipe data heterogen.

Karakteristik Utama List

  • Tanda Kurung Siku: Dideklarasikan menggunakan simbol kurung siku [ ].
  • Ordered (Berurutan): Setiap elemen memiliki posisi tetap berdasarkan nomor indeks.
  • Mutable (Bisa Diubah): Elemen di dalam list bisa ditambah, dihapus, ditukar, atau diurutkan ulang.
  • Heterogen: Bisa berisi campuran integer, float, string, boolean, bahkan list lain (nested).
contoh_list.py 
# Deklarasi berbagai macam list
list_angka = [200, 400, 600]
list_huruf = ["Hallo", "Hai", "UNM"]
list_campuran = [1, "Hallo", 3.14, True]

print(list_angka[0])  # Output: 200 (Indeks ke-0)
print(list_angka[-1]) # Output: 600 (Elemen terakhir)

Aturan Indexing Python (Positif & Negatif)

Python memiliki fitur istimewa yaitu Dual Indexing System. Anda bisa mengakses dari depan (mulai 0) maupun dari belakang (mulai -1).

Rumus Indeks Positif vs Negatif

• Indeks Positif (0 s/d n-1): Bergerak dari kiri ke kanan. Dimulai dari angka 0.
• Indeks Negatif (-1 s/d -n): Bergerak dari kanan ke kiri. Elemen paling ujung kanan selalu berindeks -1.

Bagian 02

Teknik Mengiris Data: List Slicing

Slicing memungkinkan kita mengambil sub-bagian list dengan format jangkauan list[start : stop : step].

Sintaks Jangkauan [start : stop : step]

• start: Indeks awal pengambilan data (inklusif / ikut terambil).
• stop: Batas indeks akhir pengambilan (eksklusif / tidak ikut terambil).
• step: Interval loncatan antar elemen (default = 1).

Contoh Cepat Populer: data[:4] # Ambil 4 elemen pertama (0..3) data[2:] # Ambil dari indeks ke-2 sampai akhir data[::2] # Ambil elemen dengan langkah loncat 2 data[::-1] # Membalik urutan list (Reverse)

Bagian 03

Operasi & Method Lengkap pada List

Python menyediakan segudang built-in methods canggih untuk menambah, menghapus, mengurutkan, dan menganalisis elemen list.

1. Menambahkan Elemen

  • append(x): Menambahkan data x di posisi paling akhir list.
  • insert(i, x): Menyisipkan data x pada indeks ke-i.
  • extend(list2): Menggabungkan seluruh elemen dari list lain.

2. Menghapus Elemen

  • remove(val): Menghapus data pertama yang bernilai val.
  • pop(i): Menghapus & mengembalikan elemen pada indeks i (default: terakhir).
  • clear(): Mengosongkan seluruh elemen list menjadi [].
  • del list[i]: Menghapus elemen berdasarkan indeks/slice.

3. Mengurutkan & Mencari

  • sort(): Mengurutkan elemen dari terkecil ke terbesar (Ascending).
  • sort(reverse=True): Mengurutkan dari terbesar ke terkecil (Descending).
  • reverse(): Membalik urutan data tanpa mengurutkan nilai.
  • index(x): Menemukan nomor indeks dari data x.
  • count(x): Menghitung jumlah kemunculan data x.

Bagian 04

Konsep Tuple: Mengapa Harus Immutable?

Tuple adalah struktur data berurutan seperti List, namun bersifat Immutable (tidak dapat diganggu gugat / tidak bisa diubah setelah dibuat).

Mengapa Kita Membutuhkan Tuple?

Meskipun terlihat mirip dengan List, Tuple memiliki peranan krusial dalam arsitektur perangkat lunak Python:

  • Data Integrity & Safety: Melindungi data konstan (koordinat GPS, konfigurasi server, dimensi layar, hari dalam seminggu) agar tidak sengaja termodifikasi oleh fungsi lain.
  • Performa Eksekusi Cepat: Tuple dialokasikan dalam satu blok memori statis sehingga jauh lebih cepat dan hemat memori dibanding List.
  • Dictionary Key: Tuple bersifat hashable sehingga dapat dijadikan kunci (key) pada Dictionary Python, sedangkan List tidak bisa.
Jebakan Single-Element Tuple!

Jika Anda ingin membuat Tuple yang hanya berisi 1 elemen, WAJIB menambahkan tanda koma , di belakangnya!
t = (50,) → Tipe Tuple
t = (50) → Tipe Integer (Python menganggapnya ekspresi kurung matematika biasa!)

Tabel Komparasi List vs Tuple

Kriteria List [ ] Tuple ( )
Sifat Mutable (Bisa diedit) Immutable (Terkunci)
Simbol Kurung siku [ ] Kurung biasa ( )
Ukuran Memori Dinamis & Lebih Besar Statis & Sangat Ringan
Method Banyak (append, pop, sort, dll) Sedikit (hanya count & index)

Bagian 05

List Multi-Dimensi (Nested List / 2D Matrix)

Ketika sebuah list berisi list lain di dalamnya, kita membentuk struktur matriks berdimensi dua dengan konsep matrix[baris][kolom].

Konsep Baris dan Kolom Matriks

Untuk mengakses sel pada matriks 2D, indeks pertama menentukan nomor baris, dan indeks kedua menentukan nomor kolom.

matriks_2d.py 
matriks = [
    [1, 2, 3],  # Baris indeks 0
    [4, 5, 6],  # Baris indeks 1
    [7, 8, 9]   # Baris indeks 2
]

# Mengakses angka 8 (Baris 2, Kolom 1)
print(matriks[2][1])  # Output: 8

# Mengubah angka 5 menjadi 50
matriks[1][1] = 50

Studi Kasus Akbar: Pengolahan Rekap Nilai Mahasiswa

Integrasi pengulangan (Looping) dengan struktur data List paralel untuk input, kalkulasi nilai total/rata-rata, dan cetak laporan ASCII tabel.

Logika Pemrosesan Data Paralel

Pada sistem akademik sederhana, kita menggunakan beberapa list penampung paralel:

  • list_nim = [] → Menyimpan string identitas mahasiswa.
  • list_uts = [] → Menyimpan nilai integer UTS.
  • list_uas = [] → Menyimpan nilai integer UAS.
  • list_total = [] → Menyimpan hasil kalkulasi (uts + uas) / 2.
rekap_nilai.py 
# Loop kalkulasi nilai akhir
for i in range(jumlah_mhs):
    nilai_akhir = (list_uts[i] + list_uas[i]) / 2
    list_total.append(nilai_akhir)
